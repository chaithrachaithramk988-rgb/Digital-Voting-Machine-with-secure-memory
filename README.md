# Digital-Voting-Machine-with-secure-memory

🎯 Objective

To design and simulate a digital logic-based home automation system using Arduino Uno and Tinkercad. The system controls home lighting based on simulated motion and darkness inputs using AND logic.

📝 Project Summary

This project demonstrates a basic home automation system using an Arduino Uno in the Tinkercad simulation environment.

Two push buttons simulate a motion sensor and a darkness sensor. The Arduino processes these inputs using AND logic to control an LED representing a home light.

💡 The light turns ON only when both motion is detected and the room is dark. Otherwise, the light remains OFF.

This project demonstrates digital logic, Boolean operations, automated lighting control, and basic energy-saving techniques without requiring physical hardware.

🛠️ Tools and Technologies Used

- 🔌 Tinkercad Circuits – Virtual circuit design and simulation
- 🖥️ Arduino Uno R3 – Digital input and output control
- 💻 Arduino C/C++ – Programming the control logic
- 🔘 Push Buttons – Simulated motion and darkness inputs
- 💡 LED – Represents the home lighting system
- 🛡️ 220 Ω Resistor – Limits current through the LED
- 🧩 Breadboard and Jumper Wires – Virtual circuit connections
- ⚙️ AND Logic – Controls the light based on both input conditions

📊 Truth Table

Motion| Darkness| Light Output
0| 0| OFF
0| 1| OFF
1| 0| OFF
1| 1| ON

✅ Result

The system is designed to switch the LED ON when both simulated motion and darkness inputs are active. The LED remains OFF if either condition is inactive.

The Tinkercad simulation demonstrates the working principle of digital logic-based home automation and automated lighting control.
